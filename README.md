# jaikuaa: Your Language Journey

Create a language learning app called "Aranduka" 

(a Paraguayan platform to learn languages, with 

Guaraní at its heart. "Aranduka" means "book" in 

Guaraní).

DESIGN IDENTITY:

- Colors: navy blue #1E3A5F, red #C8102E, white 

  (the colors of the Paraguayan flag)

- Modern, clean, mobile-first design

- Warm, educational feel with Paraguayan identity

START WITH the landing/home page:

- Header with the app name "Aranduka" and a 

  jaguar emoji 🐆

- Big title: "Aprendé idiomas. Cambiá tu vida."

- Subtitle: "La primera plataforma paraguaya de 

  idiomas, con el guaraní en el corazón."

- A red button that says "Empezar gratis"

- Below, three cards showing featured languages: 

  Guaraní, Inglés, Portugués

- A small tagline at the bottom: "Aprendé · 

  Hablá · Ñane Ñe'ẽ"

All text in Spanish (Paraguayan). Make it look 

professional and beautiful.
